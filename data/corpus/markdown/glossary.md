# Glossary

## Terms

The terms below are used throughout the fleet documentation with the meanings given here. Where a manual and a shift note use the same word differently, this definition is the one that was intended.

| Term | Definition |
| --- | --- |
| Squeegee | The rubber blade assembly trailing the brush deck. It wipes the film of dirty solution into the suction path so the floor is left dry enough to walk on immediately behind the machine. |
| Solution tank | The clean-water tank. Holds water and metered detergent before it reaches the brush deck. |
| Recovery tank | The dirty-water tank. Takes back everything the solution tank puts down plus the soil lifted with it, and is therefore never smaller than the solution tank. |
| Brush deck | The housing carrying the scrubbing brushes or pad drivers, together with the mechanism that raises and lowers them. |
| C-rate | Charge or discharge current expressed as a multiple of the battery's rated capacity. A 100 Ah pack charged at 0.5C draws 50 A. |
| Deep discharge | Discharging a battery below its permitted minimum state of charge. Permanently reduces capacity, and on lithium packs the damage is not visible until the pack is next load-tested. |
| Hopper | The debris container on a sweeper. Sweeping performance falls off well before the hopper is visibly full, because the filter blinds first. |
| Filter shaker | The mechanism that knocks dust off the panel filter. Run it before emptying the hopper, never after. |
| Pad driver | The disc that holds a cleaning pad in place of a brush, used where the floor finish would be damaged by bristles. |
| Wear limit | The dimension at which a consumable must be replaced. Running past it damages the part the consumable protects, which is always the expensive one. |
