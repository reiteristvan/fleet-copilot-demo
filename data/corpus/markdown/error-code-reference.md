# Error code reference

## Codes

Every code the machines in this fleet display, with the machine types it can appear on. A code that recurs after clearing is a fault report even if the machine keeps running.

| Code | Meaning | Applies to |
| --- | --- | --- |
| E-017 | Squeegee lift fault | SD-50B, SDR-90 |
| E-041 | Battery over-temperature | SD-50B, SDR-90, SWR-120, VS-75, SDM-43 |
| E-052 | Recovery tank full | SD-50B, SDR-90 |
| E-063 | Brush motor overload | SD-50B, SDR-90, SWR-120, SDM-43 |
| E-074 | Solution flow blocked | SD-50B, SDR-90 |
| E-088 | Traction motor overcurrent | SDR-90, SWR-120 |
| E-101 | Charger communication lost | SD-50B, SDR-90, SWR-120, VS-75, SDM-43 |
| E-113 | Side broom jam | SWR-120, VS-75 |
| E-126 | Filter shaker failure | SWR-120, VS-75 |
| E-134 | Hopper not seated | SWR-120, VS-75 |
| E-147 | Deep discharge lockout | SD-50B, SDR-90, SWR-120, VS-75, SDM-43 |
| E-152 | Vacuum motor over-temperature | VS-75 |

## Guidance

- Codes are per machine type. The same number on a different machine type may mean something else, so check the type before acting on it.
- Record the code before clearing it. Clearing the fault history discards the only evidence of how often it has occurred.
