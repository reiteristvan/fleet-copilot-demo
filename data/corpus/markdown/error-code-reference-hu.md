# Hibakód jegyzék

## Kódok

Kijelzőkódok és jelentésük. A kód azt azonosítja, amit a gép érzékelt, nem az okot; az okot az adott kódhoz tartozó szervizeljárás állapítja meg.

| Code | Meaning | Applies to |
| --- | --- | --- |
| E-017 | Lehúzógumi emelési hiba | SD-50B, SDR-90 |
| E-041 | Akkumulátor túlmelegedés | SD-50B, SDR-90, SWR-120, VS-75, SDM-43 |
| E-052 | Szennyvíztartály tele | SD-50B, SDR-90 |
| E-063 | Kefemotor túlterhelés | SD-50B, SDR-90, SWR-120, SDM-43 |
| E-074 | Oldatáramlás elzáródott | SD-50B, SDR-90 |
| E-088 | Hajtómotor túláram | SDR-90, SWR-120 |
| E-101 | Töltő kommunikáció megszakadt | SD-50B, SDR-90, SWR-120, VS-75, SDM-43 |
| E-113 | Oldalkefe elakadás | SWR-120, VS-75 |
| E-126 | Szűrőrázó meghibásodás | SWR-120, VS-75 |
| E-134 | Szeméttartály nincs a helyén | SWR-120, VS-75 |
| E-147 | Mélykisütés elleni zárolás | SD-50B, SDR-90, SWR-120, VS-75, SDM-43 |
| E-152 | Szívómotor túlmelegedés | VS-75 |

## Útmutató

- Az újraindításkor magától törlődő kód nem megoldódott, hanem elfelejtődött, és a mögöttes állapot rendszerint továbbra is fennáll.
- A kód törlése előtt jegyezze fel. A hibanapló törlése megsemmisíti az egyetlen bizonyítékot arra, hogy a hiba milyen gyakran fordult elő.
